# Human Atlas originality record

Human Atlas is being developed as an independent product. The project may use commonplace ideas in 3D anatomy software — orbit controls, search, labels, system filters, transparency, and structure selection — but its visual expression, terminology, information architecture, and signature interactions are intentionally original.

## Product language

Human Atlas is organized around five verbs:

- Explore
- Reveal
- X-Ray
- Relate
- Trace

Its core metaphor is a **Living Map** with adaptive **Living Labels** and a **Depth** control from Surface to Core.

## Deliberate non-copying constraints

Do not reproduce a third-party product's exact screen layout, distinctive control placement, wording, onboarding copy, icon arrangement, signature animations, label treatment, visual proportions, or proprietary anatomical assets without a valid license.

Reference products can inform broad usability questions, but implementation decisions must be independently authored and recorded in this repository.

## Development evidence

Preserve Git history, design notes, issues, and pull requests as a dated record of independent development. This file is product-development documentation, not a legal opinion or substitute for IP counsel.

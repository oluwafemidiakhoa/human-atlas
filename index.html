SOURCE / PROVENANCE / SCOPE

Body Cartography

Human Atlas — Body Cartography is an independently designed anatomy-learning interface centered on stable spatial context: Survey, Dissect, Ghost and Lineage.

The geometry package is BodyParts3D 4.0 adult male reference anatomy. Every imported source mesh remains individually addressable. Region tags are navigation aids derived by Human Atlas and are not presented as original BodyParts3D ontology fields.

This experience is educational and is not a diagnostic or clinical decision-support tool.
